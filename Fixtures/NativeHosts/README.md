# Controlled native host fixtures

Original MV2/MV3 CRX3 packages generated by `script/generate_native_fixtures.py` with ephemeral P-256 keys; private keys are never written. Regeneration changes identities. The options page requests nativeMessaging and exercises the real production registration, permission, stdio and port routes. `script/NativeHostFixture.swift` is built and ad-hoc signed with minimum/SDK macOS 27.0 during CI. It echoes framed JSON, caller origin and its process ID; it performs no file access, network requests or child launches. This fixture is not a third-party extension compatibility result.
